Sem IV CSE at ITM Skills University. I ship Shopify themes for founder-led brands, build editorial frontends in Next.js with GSAP and Three, and lose evenings to WorldQuant BRAIN and multi-agent LLM tooling. Not a generalist by conviction — a generalist by curiosity.

### Currently building

- **[Studio Caramel](https://github.com/Sayuj63/CARAMEL-STUDIO)** &nbsp;·&nbsp; a photographer's portfolio on Next 16 + GSAP + Framer + Three.js. Editorial pacing, custom cursor, theme-inverting sections, full mobile.
- **[Donna](https://github.com/Sayuj63/donna-voice-hermes)** &nbsp;·&nbsp; a low-latency voice agent stitched from Cloudflare Workers, WebRTC, and the OpenAI Realtime API. Built in 2h.
- Ten-plus live Shopify themes across Adore Nails, ISOA, Almost Always, Calvium, TCC, Apurvi, Seba Digital, and Fitkaar.

### Stack

`TypeScript` · `Next.js` · `React` · `GSAP` · `Framer Motion` · `Three.js` · `Liquid` · `Shopify CLI` · `Python` · `FastAPI` · `Cloudflare Workers` · `WorldQuant BRAIN`
